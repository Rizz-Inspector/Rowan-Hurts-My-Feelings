Basic controls (mobility):

hold left on mouse to shoot projectiles

hold w to accelerate forward

hold a to turn left

In game usage controls:

press [enter] to proceed or start 

x to set gun mode to manual (where your gun aims at your mouse)

z to set gun mode to default (where you only shoot at the front of the vehicle)

c to set gun mode to auto (Not Recommended: where the system automatically shoots at the closest enemy)

press 1 to switch gun type to minigun

enemies like drones and small combat spacecrafts (etc. bomber). The big gunship has 3 phase, the first phase is a shield and it can be disabled

large health bar where you have to engage extreme crossfire fights with more incoming spacecrafts and destroy the gunship by shooting it until it
loses all of it's health. Then you win! Good luck and try not to die though.
